## ⚡ Overview
**ZYNTRA '26** is the premier annual technology festival organized by Sapthagiri NPS University. Built with an immersive 3D cosmos background in Three.js, a custom cyber targeting reticle cursor, high-speed audio telemetry synthesizer, and a complete 5-step project team entry portal.

## 🚀 Key Modules
1. **Interactive 3D Cosmos Background**: Responsive camera fly-through and core zoom animation linked to scroll depth.
2. **5-Step Project Team Entry Portal (`#register`)**:
   - **Step 1 — Team**: Leader information (Name, SRN/USN, College Email, Phone, Dept, Semester).
   - **Step 2 — Members**: 2 to 5 students total (Member 2 mandatory + dynamic slots 3–5 with add/remove).
   - **Step 3 — Project**: Domain track, key technologies, project abstract (with live word counter), mentor name, and GitHub repository demo link.
   - **Step 4 — Review**: Comprehensive review cards with direct edit links and code of conduct declaration.
   - **Step 5 — Payment & Pass**: Flat ₹500 fee summary, Instant UPI QR (`zyntrasnpsu@upi`), Bank Transfer, UTR verification, and digital pass generation with QR code and print/download pass options.
3. **Admin Command Center (`#admin`)**:
   - Protected with passcode authentication (`zyntra2026`).
   - Real-time tabular inspection of all registered teams, leaders, member rosters, and UTR reference IDs.
   - One-click CSV spreadsheet export for offline coordination.

## 🛠️ Technology Stack
- **Frontend**: React 19, Vite, Three.js, Lucide Icons, Canvas Confetti, Tailwind CSS.
- **Backend / API**: Express.js, CORS, Sliding-window rate limiters, honeypot bot defense, atomic persistence engine.
- **Deployment**: Zero-config Vercel SPA routing (`vercel.json`).

## 💻 Local Development
```bash
# Clone the repository
git clone https://github.com/Nithin21-03/techfest.git
cd techfest

# Install dependencies
npm install

# Run development server (Frontend + Backend)
npm run dev

# Or run client only
npm run dev:client

# Production Build
npm run build
```
